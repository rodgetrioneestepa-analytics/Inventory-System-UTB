# Inventory web application

- `frontend/`: React pages, forms, styles and browser API client.
- `backend/src/`: Express API, authentication, inventory ledger, imports and setup commands.
- `shared/`: API types used by the frontend.

Run all `npm` commands from the repository root. Build and test configuration is in `config/`, SQL migrations are in `database/migrations/`, and tests are in `tests/`.

See [setup instructions](../readme/SETUP.md) and [API documentation](../readme/API.md).
